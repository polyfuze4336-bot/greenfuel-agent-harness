5 Recommendation

Recommend sovereign cells, a deterministic core and bounded agents

Evidence stays in its port. Software computes and signs. AI drafts and explains, and never decides.

DESIGN docs/target-architecture/03-ARCHITECTURE-VIEWS.md   DESIGN docs/architecture/designs/DES-0003-target-system-architecture.md
M06 · 6/28
Say (90s): One cell per port jurisdiction holds that port's evidence and runs the deterministic services: ingestion and verification, calculation under a versioned methodology, certificate signing, approvals. Agents sit on top, optional and bounded, and never hold the permission to approve or file. A thin group plane distributes signed methodology versions and receives only data classes on an approved flow list. The edge captures, signs and buffers, because the link is intermittent. Azure is used where residency is verified; otherwise the cell runs on a local host. All of this is a proposal: the design record is Proposed, not approved.
