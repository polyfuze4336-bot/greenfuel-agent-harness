## Findings on the proposal, most serious first

**1. The trace table reads as satisfied when the proposal's own verdict path says unresolved.**

- The line "Option B is the only one with a written path against HC-01 … HC-12" claims more than the evidence supports. A "written path" is not satisfaction, and HC-12 is "satisfied" only by the author's self-assertion.
- Cheapest test: record a per-constraint verdict (Satisfied, Conditional, Violated, Unresolved, Not applicable) for Option B, using the gate's vocabulary.

**2. Shape item 1 contradicts HC-02.**
- Item 1 places "identity and key management for that cell" at cell level, shared by every shipowner in it.
- HC-02's reject-when test names a shared "credential" and a shared "log view". Item 2 isolates only storage container, keys, credentials, index and compute.
- Item 1 also puts logs and telemetry at cell level. The proposal never says whether the cell-level identity, key and log services are per-shipowner.
- R5 admits key custody design is "open".
- Cheapest test: list every cell-level component and mark each shared or per-shipowner. Any "shared" entry is a candidate HC-02 violation.

**3. Alternatives are largely straw men.**
- Option C is rejected by its own Con ("which SEC-001 and HC-01 reject"). It was a dominated option from the start.

  - edge-hosted versus shore-hosted first record.
- Option B's "Pro: addresses HC-01 … together" is stated as fact. It is a design intent, with no evidence behind it.
- Cheapest test: ask the author to show one alternative to B that is not eliminated by a hard constraint, and the criterion used to pick between them.

**4. Evidence versus claim on edge-first integrity (HC-07, HC-08, FR-006, SEC-008).**
- FR-006 says "shore copy matches edge hashes". The only reference for tamper checks is therefore the edge chain, which is not independent.
- An attacker, a fault or a compromised edge can alter or truncate the chain before first upload. Nothing downstream can detect that.
- A per-delivery hash chain does not by itself reveal tail truncation or deletion of a whole delivery. Anchors are "periodic", which leaves a window.
- Item 5 says the verifier tests replay and reordering. A hash chain gives no stated replay protection across deliveries or sessions.
- SEC-008 demands that modification or deletion is "always detected".
- R4 admits its mitigation is "effectiveness unverified". Signing is optional ("if the meter or logger supports it").
- Cheapest test: a tamper-test matrix for modify, delete the tail, delete a whole delivery, reorder and replay. Run it against a paper design first and state the detection point for each case.

**5. Unstated assumption: where the edge sits.**
- The proposal never says where the edge device is or who owns it. The edge keeps a persistent local log. If it is on a vessel or barge that sails, the data is stored outside the originating jurisdiction.
- HC-01 forbids storing or administering data outside the jurisdiction, and the proposal's own "Edge first" item makes the edge the first writer of record.
- The edge is not named as a cell component in shape item 1.
- Cheapest test: add the edge to the SEC-001 flow inventory and state its location after departure.

**6. Unstated assumption: the consumers of the evidence.**
- Delivery evidence packages (DC-02) are meant to be read by shipowners, certifiers or verifiers. Nothing says these readers are in-jurisdiction.
- Any outward delivery of packages is a cross-border flow needing D-011 and a legal basis.
- This is the main business use of the store, and it is absent from the trace and the risks.
- Cheapest test: enumerate the readers of the evidence and where each sits, against the flows on the SEC-001 inventory.

**7. Derived data and verifier location are unaddressed (HC-01, FR-001).**
- The proposal says derived values "reference" raw ones. It does not say where derived values are computed or stored.
- HC-01 covers anything derived and any processing outside the jurisdiction, including AI inference.
- The verifier's location is unspecified. It reads the full chains of every shipowner, so it is either a shared component (HC-02) or an outside reader (HC-01).
- "Independent" is also undefined: independent of whom, and does an independent in-jurisdiction party exist per port? That is an unlabelled assumption.
- Cheapest test: name the verifier's operator and location, and say how it is separated per shipowner.

**8. Non-resolution of retention against append-only.**
- D-015 is open. If a retention period ends, deletion must be detectable under SEC-008.
- The proposal handles correction (FR-030) but not expiry or legal-hold deletion. Cheapest test: write one scenario for a record reaching expiry.

**9. Citations without trace.**

- SEC-006 requires "automated adversarial tests … zero cross-tenant disclosures". The proposal offers only "tested isolation" (R5).
- Neither the HC-12 "no figures" claim nor the "FACT" labels have an EV record. The author admits they were not re-checked.

**10. Where the proposal survived.**
